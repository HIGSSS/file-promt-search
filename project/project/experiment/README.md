# Эксперимент: Precision@5

Эксперимент из §7.2 ТЗ. Цель — показать, что семантический поиск
существенно превосходит точный подстрочный поиск по имени файла
на описательных запросах, и сопоставим с ним на точных.

## Файлы

| Файл                    | Назначение |
|-------------------------|-----------|
| `generate_dataset.py`   | Генерирует 50 тестовых файлов (20 изображений + 15 документов + 15 прочих) |
| `queries.json`          | 20 запросов: 10 точных + 10 семантических, с ground truth |
| `run_experiment.py`     | Считает Precision@5 для семантики и подстроки, печатает отчёт |

## Пошаговая инструкция

### 1. Сгенерировать датасет

```bash
cd experiment
python3 generate_dataset.py --out ./test_dataset
```

Создаст 50 файлов и `_manifest.json` в `./test_dataset/`.
Зависимости для генерации: `pillow`, `pymupdf`, `python-docx`, `openpyxl`.

### 2. Запустить backend

В отдельном терминале:

```bash
cd ../backend
./run_server.sh
```

### 3. Проиндексировать датасет

```bash
# Абсолютный путь обязателен
curl -X POST http://localhost:8000/index \
    -H "Content-Type: application/json" \
    -d "{\"path\": \"$(realpath ./test_dataset)\"}"

# Ждём завершения (проверять каждые несколько секунд)
watch -n 2 'curl -s http://localhost:8000/status'
```

Индексация 50 файлов на CPU занимает ~2–5 минут.

### 4. Запустить эксперимент

```bash
python3 run_experiment.py --server http://localhost:8000 --out report.json
```

## Ожидаемый результат

Согласно §7.2 ТЗ:
- На **семантических запросах**: семантический поиск ≥ 70%, подстрочный 0–20%.
- На **точных запросах**: оба метода близки (70–100%).
- **В среднем**: семантический поиск значительно обгоняет подстрочный.

Именно эта картина и является ключевым аргументом ВКР: семантика даёт
пользу там, где имя файла не описывает содержимое (что на практике
характерно для большинства файлов — IMG_20240315_114522.jpg и т. п.).

## Дизайн датасета

Имена файлов в датасете **не описывают содержимое**:
- Все изображения — `IMG_0001.png` … `IMG_0020.png`
- Документы/таблицы — `FILE_0001.pdf` … `FILE_0025.xlsx`
- Только 5 «прочих» файлов имеют осмысленные имена (тестируют fallback-индексацию по имени)

Содержимое разнообразное, с кириллицей. Запросы намеренно включают
как точные (по ID файла или по осмысленному имени), так и описательные
(«кошка у окна», «договор аренды»), чтобы увидеть оба режима работы.

Вывод `run_experiment.py`:

```
 РЕЗУЛЬТАТЫ ЭКСПЕРИМЕНТА: Precision@5
 ======================================================================
 Набор                              Семантика      Подстрока
 ------------------------------------------------------------
 Все запросы (N=20)                       XX.X%        XX.X%
   из них точные (N=10)                   XX.X%        XX.X%
   из них семантические (N=10)            XX.X%        XX.X%
```

И детализация по каждому запросу. Сохранённый `report.json` удобно
цитировать в тексте ВКР — там лежат все `semantic_top` / `substring_top`
списки для полной воспроизводимости.
