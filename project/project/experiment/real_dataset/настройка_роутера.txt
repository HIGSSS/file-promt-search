Инструкция по настройке роутера TP-Link для домашней сети

Шаг 1. Физическое подключение
Подключите кабель провайдера (интернет) в порт WAN (синий). Компьютер или ноутбук подключите в один из портов LAN (жёлтые). Включите роутер в розетку.

Шаг 2. Вход в веб-интерфейс
Откройте браузер и перейдите по адресу http://192.168.0.1 (или 192.168.1.1). Введите логин: admin, пароль: admin (указаны на наклейке снизу роутера).

Шаг 3. Настройка интернета
Перейдите в «Базовая настройка» → «Интернет». Выберите тип подключения PPPoE. Введите логин и пароль от провайдера (из договора). Нажмите «Сохранить».

Шаг 4. Настройка WiFi
Раздел «Беспроводная сеть». Задайте имя сети (SSID) и надёжный пароль (минимум 8 символов, буквы + цифры). Стандарт: 802.11ac (5 ГГц) для скорости или 802.11n (2,4 ГГц) для большего радиуса. Нажмите «Сохранить».
